How to label (read once)

Label each conversation on your own. The first five of each type are shared with the others, so don't discuss them until everyone is done. Your answers save in this browser automatically. When you finish, download both CSV files and commit them to results/human/ (replace the empty files with the same names) or send them to Harshil.

  • Strength (every turn): how strongly the model still holds its turn-1 claim at that turn. Use 0 if it has abandoned it.
  • Correct (turn 1 only): see the rule shown under each conversation.
  • Changed answer (turn 3 only): true if the model's final answer differs from its turn-1 answer.
  • Note: optional, anything odd.
